# road-safety-project



This project was completed individually for the Milestone 2/3 assessment. It utilizes Python, Flask, and SQLite to analyze and visualize Victorian road crash data.



Features;

Project Mission: Dynamic mission statement management.

Data Summaries: Persona-based views for "Long-distance Commuters" and "Cyclists."

Risk Discovery: Insights into high-risk road geometries and accident trends.



Setup Instructions

To run this application on your local machine, follow these steps:



1. Ensure you have Python and Flask installed.

2\. Clone this repository to your local machine.



Installation

Open your terminal/command prompt in the project folder and run:

run 'pip install flask pandas'



to initialize database

run 'python init\_db.py'



to run webserver

run 'python app.py'

then navigate to http://127.0.0.1:5000 in your web browser
